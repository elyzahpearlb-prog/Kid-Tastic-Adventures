# Kid-Tastic Adventures

## Project Description

Kid-Tastic Adventures is an interactive educational website designed for preschool to Grade 1 children. It aims to make learning more enjoyable by combining educational activities with simple and engaging games.

The project addresses the problem of children becoming bored with traditional learning activities by turning screen time into learning time.

## Features

- Math Activities
- Color Recognition
- Counting Games
- Animal Identification
- Shape Learning
- Memory Games
- Listen and Read
- Number Comparison
- Alphabet Tracing
- Number Tracing

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation/Usage

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Choose an activity and start learning.
